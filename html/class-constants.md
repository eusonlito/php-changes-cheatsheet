# [New Class Constants in PHP 5.3, 5.2](index.md)

# [PHP 5.3](https://php-legacy-docs.zend.com/manual/php5/en/migration53.class-constants.php)

## New Class Constants

Several new class constants were introduced in 5.3.0:

[PDO_FIREBIRD](https://php-legacy-docs.zend.com/manual/php5/en/ref.pdo-firebird.html):

- **`PDO::FB_ATTR_DATE_FORMAT`** - Sets the format for dates.
- **`PDO::FB_ATTR_TIME_FORMAT`** - Sets the format for time.
- **`PDO::FB_ATTR_TIMESTAMP_FORMAT`** - Sets the format for timestamps.

# [PHP 5.2](https://php-legacy-docs.zend.com/manual/php5/en/migration52.class-constants.php)

## New Class Constants

[pdo](https://php-legacy-docs.zend.com/manual/php5/en/intro.pdo.html):

- **`PDO::ATTR_DEFAULT_FETCH_MODE`**
- **`PDO::FETCH_PROPS_LATE`**
- **`PDO::FETCH_KEY_PAIR`** Fetches a 2 column result set into an associated array. (Added in PHP 5.2.3)

[spl](https://php-legacy-docs.zend.com/manual/php5/en/ref.spl.html):

- **`CachingIterator::FULL_CACHE`**
- **`CachingIterator::TOSTRING_USE_INNER`**
- **`SplFileObject::READ_AHEAD`**
- **`SplFileObject::READ_CSV`**
- **`SplFileObject::SKIP_EMPTY`**
