# [PHP 5.5](https://php-legacy-docs.zend.com/manual/php5/en/migration55.changes.php)

## What has changed in PHP 5.5.x

Most improvements in PHP 5.5.x have no impact on existing code. There are a [few incompatibilities](https://php-legacy-docs.zend.com/manual/php5/en/migration55.incompatible.html) and [new features](https://php-legacy-docs.zend.com/manual/php5/en/migration55.new-features.html) that should be considered, and code should be tested before switching PHP versions in production environments.

For systems being upgraded from an older version of PHP, the relevant documentation is available at:

- [Upgrade Notes for PHP 5.4.x](https://php-legacy-docs.zend.com/manual/php5/en/migration54.html).
- [Upgrade Notes for PHP 5.3.x](https://php-legacy-docs.zend.com/manual/php5/en/migration53.html).
- [Upgrade Notes for PHP 5.2.x](https://php-legacy-docs.zend.com/manual/php5/en/migration52.html).
- [Upgrade Notes for PHP 5.1.x](https://php-legacy-docs.zend.com/manual/php5/en/migration51.html).
- [Migrating from PHP 4 to PHP 5](https://php-legacy-docs.zend.com/manual/php5/en/migration5.html).

# [PHP 5.1](https://php-legacy-docs.zend.com/manual/php5/en/migration51.changes.php)

## Key PHP 5.1.x features

Some of the key features of PHP 5.1.x include:

- A complete rewrite of date handling code, with improved timezone support.

- Significant performance improvements compared to PHP 5.0.X.

- PDO extension is now enabled by default.

- Over 30 new functions in various extensions and built-in functionality.

- Over 400 various bug fixes.

# [PHP 5.0](https://php-legacy-docs.zend.com/manual/php5/en/migration5.changes.php)

## What has changed in PHP 5.0.x

PHP 5 and the integrated Zend Engine 2 have greatly improved PHP's performance and capabilities, but great care has been taken to break as little existing code as possible. So migrating your code from PHP 4 to 5 should be very easy. Most existing PHP 4 code should be ready to run without changes, but you should still know about the [few differences](https://php-legacy-docs.zend.com/manual/php5/en/migration5.incompatible.html) and take care to test your code before switching versions in production environments.
