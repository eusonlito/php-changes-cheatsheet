# [Removed Extensions in PHP 8.4, 7.4, 5.4, 5.3, 5.2](index.md)

# [PHP 8.4](https://www.php.net/manual/en/migration84.removed-extensions.php)

## Removed Extensions

These extensions have been moved to PECL and are no longer part of the PHP distribution. New releases for the PECL packages will be published on an ad-hoc basis according to user demand.

- [IMAP](https://www.php.net/manual/en/book.imap.php)
- [OCI8](https://www.php.net/manual/en/book.oci8.php)
- [PDO_OCI](https://www.php.net/manual/en/ref.pdo-oci.php)
- [PSpell](https://www.php.net/manual/en/book.pspell.php)

# [PHP 7.4](https://www.php.net/manual/en/migration74.removed-extensions.php)

## Removed Extensions

These extensions have been moved to PECL and are no longer part of the PHP distribution. The PECL package versions of these extensions will be created according to user demand.

- [Firebird/Interbase](https://www.php.net/manual/en/book.ibase.php) - access to an InterBase and/or Firebird based database is still available with the PDO Firebird driver.

- [Recode](https://www.php.net/manual/en/book.recode.php)

- [WDDX](https://www.php.net/manual/en/book.wddx.php)

# [PHP 5.4](https://php-legacy-docs.zend.com/manual/php5/en/migration54.removed-extensions.php)

## Removed Extensions

These extensions have been moved to PECL and are no longer part of the PHP distribution. The PECL package versions of these extensions will be created according to user demand.

- [sqlite](https://php-legacy-docs.zend.com/manual/php5/en/book.sqlite.html) - Note that ext/sqlite3 and ext/pdo_sqlite are not affected

# [PHP 5.3](https://php-legacy-docs.zend.com/manual/php5/en/migration53.removed-extensions.php)

## Removed Extensions

These extensions have been moved to PECL and are no longer part of the PHP distribution. The PECL package versions of these extensions will be created according to user demand.

- [dbase](https://php-legacy-docs.zend.com/manual/php5/en/book.dbase.html) - No longer maintained
- [fbsql](https://php-legacy-docs.zend.com/manual/php5/en/book.fbsql.html) - No longer maintained
- [fdf](https://php-legacy-docs.zend.com/manual/php5/en/book.fdf.html) - Maintained
- [ming](https://php-legacy-docs.zend.com/manual/php5/en/book.ming.html) - Maintained
- [msql](https://php-legacy-docs.zend.com/manual/php5/en/book.msql.html) - No longer maintained
- [ncurses](https://php-legacy-docs.zend.com/manual/php5/en/book.ncurses.html) - Maintained
- [sybase](https://php-legacy-docs.zend.com/manual/php5/en/book.sybase.html) - Discontinued; use the [sybase_ct](https://php-legacy-docs.zend.com/manual/php5/en/book.sybase.html) extension instead
- [mhash](https://php-legacy-docs.zend.com/manual/php5/en/book.mhash.html) - Discontinued; use the [hash](https://php-legacy-docs.zend.com/manual/php5/en/book.hash.html) extension instead. [hash](https://php-legacy-docs.zend.com/manual/php5/en/book.hash.html) has full mhash compatibility; all existing applications using the old functions will continue to work.
